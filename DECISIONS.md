# Apex decisions

Every design call, who made it, and why. v1 was hand-built by Gourav. From v2 on, Gourav is the
architect and decides, and Claude (AI) implements. This file is the map for learning v2 after it's built.

| Date | Decision | Who | Why |
|---|---|---|---|
| 2026-09-23 | v2 = a race engineer on the radio DURING the race: 7 seats (race engineer, strategist, spotter, performance engineer, racecraft coach, setup engineer, team memory) | Gourav | "like racing IRL, only on sim". One system with one memory finds gaps that separate tools can't |
| 2026-09-23 | DONE = one full ranked race, never switched off, every seat makes a real call | Gourav | a check that can pass, instead of "covers every aspect" |
| 2026-09-23 | Build it, don't buy Crew Chief for the basics | Gourav | tried it: static scripted spotter, no strategy, no memory of the driver |
| 2026-09-23 | Persona = Verstappen voice, swearing kept, "aggressive but TIMED" | Gourav | the original "never back down" feeds his real weakness (hasty moves in close racing cost safety rating) |
| 2026-09-23 | Team memory first. Part A (recorder sees the race) before part B (profile) | Gourav (memory first), Claude (A before B) | the v1 tape holds only his own car, so a profile would be blind to close racing |
| 2026-09-23 | Any track, not only Monza | Gourav | ranked races rotate tracks; it's for daily use |
| 2026-09-23 | Push-to-talk questions included | Gourav | real engineers answer the driver |
| 2026-09-23 | LLM cap Rs 5 per race, template lines when the cap is hit | Gourav | measured: v1 = Rs 0.62 per 3 laps; Rs 100 must last |
| 2026-09-23 | Radio lines use DeepSeek v4-flash with thinking OFF | Claude (measured) | thinking was 96% of the live-line tokens; off = 14 tokens/line, 1.8 s, about 8x cheaper |
| 2026-09-23 | Jev (decision model) deferred | Claude | waitlist only; a seat's "decide" step stays swappable for later |
| 2026-09-23 | v1 kept as a standalone copy (apex_v1_clip) for clip #1; v2 grows on main; v1.0 tag = commit b6fc35e | Gourav | record the clip without blocking the build |
| 2026-09-23 | Build all of v2 first, learn it afterwards in the v1 style | Gourav | a finished coach to race with sooner |
| 2026-09-23 | apex.db and new tapes are no longer tracked in git | Claude | the db is a cache and conflicts on merge; race tapes are tens of MB |
| 2026-09-23 | Extras E1-E19 and DONE upgrades D1-D5 added to the plan | Claude proposed, Gourav approved | he asked for anything a real team has that the 7-seat list missed |
| 2026-09-23 | Tape v2 = one file: 60 Hz car frames with a "race" line (every scoring update, ~5/s) and a "near" line (cars within 60 m, every frame) written just before the car frame they belong to | Claude | the spotter needs positions far faster than scoring gives them; recording far cars at 60 Hz would make tapes huge |
| 2026-09-23 | New CarState fields default to None | Claude | Gourav's rule: old tapes must keep working |
| 2026-09-23 | Opponents matched by mID over the whole telemetry array, never by position | Claude (measured 19 Aug) | the telemetry order differs from the scoring order; matching by position pairs the wrong cars silently |
| 2026-09-23 | audit_tape.py marks every new field LIVE / CONSTANT / DEAD before any seat relies on it | Claude | several LMU fields are known dead (forces, load); find out from data, not in a race |
| 2026-09-23 | record_race.py: tape-only recording (no voice, no LLM, no db), stops itself at session end | Claude | a 15-lap dev tape through apex.py would spend about Rs 3 on v1 coach lines nobody needs |
| 2026-09-23 | Corners on any track are learned from his laps: 5 m slices, a slice counts when braking or lateral >= 0.6 g on at least half the laps, widened to a fifth of the laps, +25 m | Claude (measured) | reproduced all 7 hand-measured Monza corners from only 3 laps, brake-point starts within 0-6 m on 11 laps |
| 2026-09-23 | A throttle lift on its own does NOT count as corner evidence | Claude (measured) | with lifts counted, warm-up/traffic lifts and the Serraglio kink became fake corners until ~11 laps |
| 2026-09-23 | Monza keeps the hand-measured map and names; learned maps are saved to track_maps/<track>.json, corners named "Turn N" and renameable by hand | Claude | his hand map is validated; a readable file lets him add real names |
| 2026-09-23 | One corner lookup (track_map.corner_at) replaces the three copies in live_telemetry | Claude | v1 defect #5: "one fact, one place decides it" (his own rule). v1 hash unchanged |
| 2026-09-23 | The radio is a Governor that decides on sim time only: urgent calls go out at once; everything else waits for a straight, one line at a time, per-seat cooldowns, stale calls dropped | Claude | a real pit wall doesn't talk mid-corner; sim-time-only decisions stay identical at any replay speed (tested: max vs 50x) |
| 2026-09-23 | Urgent lines (spotter, flags) come from a pre-rendered voice bank | Claude (measured) | edge-tts took 1381 ms live; a pre-loaded clip starts in 0.01 ms |
| 2026-09-23 | Code writes WHAT to say ("tell him: ..."), the model only restyles it; a pre-TTS gate refuses banned words, labels, over-long lines, questions and any number (digits or words) not in the facts | Claude (measured) | the first real test turned a DEFEND into "take him" and a calm-down into blame; the July persona test had a spoken FLAG_ONCE label and a 12-word line |
| 2026-09-23 | Persona lines: thinking off, ~0.8-1.4 s, ~Rs 0.02 per line (the 420-token persona prompt is most of the cost) | Claude (measured) | Rs 5 cap = ~250 lines; a race needs ~40 from the voice |
| 2026-09-23 | v1's live path (coach.py phrase_event + its own hash) retired; its detector lines became the performance seat's live cues. The old event-hash test is replaced by: detector golden (same 48 events, 21 corner stats as v1) + radio speed-invariance | Claude | v2 deliberately changes WHEN lines are said; the 60 Hz detection itself must not change |
| 2026-09-23 | Every session records how it ended (session_over / session_changed / stopped_by_driver / tape_end), track and session type; apex.py runs practice -> quali -> race in one launch and debriefs after a race | Claude | E16, and the DONE check needs to know a race ran to the flag |
| 2026-09-23 | Team memory = facts rebuilt from every drive after each session; a fact is saved only with evidence rows (FK to real events/sessions) - code refuses a fact without any | Gourav's rule ("don't make stuff up"), Claude implemented | his July design, section 8.1; tested: an evidence-less fact raises, a ghost event id fails the FK |
| 2026-09-23 | A habit needs >= 3 occurrences in >= 2 separate drives; one drive = one tape (replays never count twice) | Claude | his real db has 13 sessions but only 2 drives; counting sessions would have counted one Parabolica off 4 times |
| 2026-09-23 | Contacts are detected from the game's last-impact time: a car within 10 m = CONTACT with that driver (steam id), otherwise IMPACT | Claude | needed for close racing (his #1 weakness) and the rival dossier; the 10 m radius is GUESSED until the AI tape shows real contacts |
| 2026-09-23 | Sessions store grid, final place, track-limit steps and every rival (rivals_seen) | Claude | the rival dossier (E12) and the clean-race score (E14) are built from them |
| 2026-09-23 | Spotter = nearby cars moved into my car's frame via mOri: alongside = overlapping my 4.7 m length and 1.2-6 m to the side; "clear" only after 0.4 s empty | Claude | real spotters wait before "clear"; a car flickering at the lane edge must not fire twice. LEFT_SIGN is GUESSED (rF2 convention) until the AI tape |
| 2026-09-23 | Race engineer: formation-lap warm-up, lights out / safety car / green / blue / yellow from the voice bank; penalties, track-limit steps, damage and a gap report every 3 laps phrased on a straight | Claude | E1-E4; urgent ones must not wait for the LLM |
| 2026-09-23 | Strategist: fuel (or virtual energy, whichever is tighter) measured from his own laps, first call after 2 laps, speaks again only when fine/tight/short changes; tyre-hot, rain, last lap | Claude | never assume consumption; a fuel call every lap is noise. Tyre window 105 C is GUESSED until real temps |
| 2026-09-23 | Performance engineer: after each lap, only the ONE corner furthest below his own best min speed today, and only past 4 km/h | Claude (measured) | his per-corner spread on the 11-lap tape is 1-5 km/h; a call for every corner every lap is noise |
| 2026-09-23 | The reference on any track = the fastest same-class car in his own race, from its telemetry (opponent_corners table), needing 2+ of its laps | Claude | no free benchmark lap exists (searched 19 Aug); every race now brings its own reference |
| 2026-09-23 | Earned praise: max 2 a session, only for a measured new best lap | Gourav's July "micro-win" idea | praise that is rare and measured means something |
| 2026-09-23 | Rear-snap detector: braking + steering lock + yaw more than 1.4x what lateral g / speed explains (+0.1 rad/s) | Claude | the physics checks out on his data (ratio p50 = 1.01) and fires on 0.1% of braking frames; thresholds GUESSED, and chicane flicks (T1) may be false alarms |
| 2026-09-23 | Racecraft plans rest on one rule: a faster exit from corner N wins the pass into corner N+1. Plan = the corner where his min speed beats the rival's by 3+ km/h, then "pass into the next one. Not before" | Claude, from Gourav's "aggressive but timed" | his July persona line was exactly this; it turns hasty lunges into timed moves |
| 2026-09-23 | A fight with no corner data yet (race start) gets "stay close, wait for his mistake, no lunges"; one upgraded plan when real data arrives | Claude | lap 1 is where close-racing contact happens; the first call there should be the patient one |
| 2026-09-23 | "Not here" is urgent (voice bank), fired within 300 m before a corner where the car ahead is as quick, when 0.4 s behind | Claude | the warning must land before the braking zone, not in it |
| 2026-09-23 | Contact, a lost place, or two offs get a composure reset: no blame, no driving instruction | Gourav's July "mental reset" idea (E5) | the real-model test showed the persona adds blame unless told not to |
| 2026-09-23 | Every pass attempt (alongside the car ahead, on the brakes, in a corner) is logged with its outcome; team memory reports how many ended in contact | Claude | measures the hasty-commit habit instead of assuming it |
